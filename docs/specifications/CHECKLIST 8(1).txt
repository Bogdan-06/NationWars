CHECKLIST 8 - Update - 0.4
------------

- GENERAL - Add /nation upgrade - gives +$6/min to the capital income, gives 5 free claims. You can buy it 4 times. $1000, $1500, $2000, $2500. (NOT POSSIBLE FOR USA).

- GENERAL - Add /alliance truce offer/reject/accept/renew [country] - Doesn't need an alliance, signs with a target a non aggression pact that lasts 20min. 60sec before expiring, both sides get notified that either can use /alliance truce renew to ask the other side for another 20min of truce.

- GENERAL - Add /nation kick and /nation leave - ability to kick a member from a nation as a leader and leave a nation as a MEMBER (YOU CANNOT LEAVE A NATION IF YOURE THE LEADER). You cannot join back to that nation unless RejoinNation is set to "true"

- CONFIG - Create /configurate command - a prefix for all customization commands

- CONFIG - Switch LimitedDoctrines [t/f] from /gamerule to /configurate

- CONFIG - Add DisableEspionage [t/f] (false default) to /configurate - Disable the whole /spy command

- CONFIG - Add ScorchedEarth [t/f] (true default) to /configurate - Enables/disables the ability to destroy eachothers chunks when at war\

- CONFIG - Add InstantWar [t/f] (false default)  to /configure - Enables declaring war without justifying

- CONFIG - Add DisableDoctrine [doctrine] to /configure - Disables a chosen doctrine

- CONFIG - Add NoMercy [t/f] (false default) to /configure - Disables /peace command

- CONFIG - Add Factions [t/f] (true default) to /configure - Enables/Disables alliances

- CONFIG - Add Guarantees [t/f] (true default) to /configure - Enables/Disables ability to guarantee a nation

- CONFIG - Add LeaveNation [t/f] (false default) to /configure - Enables/Disables "/nation leave"

- CONFIG - Add RejoinNation [t/f] (false default) to /configure - If a Leader kicks you or you leave the nation by yourself, you can join it back

- CONFIG - Add Satellites [t/f] (false default) to /configure - Enables/Disables "/nation info [name]"

- CONFIG - Add Colonialism [t/f] (false default) to /configure - Lets you claim chunks that do not border national territory.

- GENERAL - Fix names of nations not showing up on claims

- GENERAL - Disable/remove /openpac-parties (we have /alliance for that)

- GENERAL - (at war) Both sides cannot attack/defend chunks when peace offer is pending

- GENERAL - Replace /nation buyclaim with /nation trade which opens up a UI (kinda like the peace deal menu) where nations can trade money, ask for $/min and trade chunks ($/min takes money from nation's income, not the treasury itself).

- ITA - Edit Developed Infrastructure: Speed II on owned claims while at peace which changes to Speed I when at war, random pay-outs for building on your territory 

- GENERAL - Create the "natural waters detector system" for UK - When claiming a chunk, script checks 8 block radius around it for biomes like: Warm Ocean, Lukewarm Ocean, Deep Lukewarm Ocean, Ocean, Deep Ocean, Cold Ocean, Deep Cold Ocean or river. Or if the biome which it is located on any of is any of the biomes said before or a beach. If the criteria are met, claim is considered a coast.

- CONFIG - Add ClaimNether [t/f] and ClaimEnd [t/f] (both false default) to /configure - ability to claim chunks in those dimensions

- CONFIG - Add SpawnProtection <number> (default 200) to configure - Adds a radius that prevents players from claiming land near spawn. <number> blocks from spawn in any direction meaning that default radius is 400x400.

- CONFIG - Add AllowTrade [t/f] (true default) to /configure - Allows /nation trade.

- USA - Edit Capitalism: Pay the claim cost to generate 0.25x worth of capital income. Cannot upgrade your nation with /nation upgrade.

- ENG - Edit Ports: coast claims produce 0.25x of the capital income.

- ENG - Edit  Sea Lion: coast claims are captured 10s faster.

- SOV - Edit Collectivity: capital doesn't produce passive income at start, however it can still be upgraded with /nation upgrade.

- GENERAL - Create "betrayal" rule - If you decline the defense of allied/guaranteed by you nation, you pay $250 penalty.

- FRA - Edit No War Support: Maintenance is raised to 1.5x when you declare war. (defensive wars do not apply)

- FRA - Edit Casus Foederis: declining defending allies and guatantees costs 3x as much as normal.

- SOV - Edit Yellow Curtains: buying from market costs 1.25x the normal price.

- SOV - Edit Great Patriotic War: Your land takes twice as long to conquer unless 2 enemy attackers are present.

- USA - Edit Worldwide Economy: All the prices on the market are 0.8x of the original price.

- ROM - Edit Iron Guard: losing a core claim raises maintenance by 0.1x (stacks)
