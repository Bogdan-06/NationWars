# Nation Wars 0.5.1 implementation report

## Scope

This release implements CHECKLIST 10 on top of the verified 0.5.0 project. It
does not perform an architectural rewrite or rebalance unrelated systems. The
pre-change source backup is recorded in `docs/current-behaviour.md`.

## Implemented changes

- Added the global maintenance, claim-cost, capital-income, counted-member, and
  paid-access server settings requested by the checklist.
- Exempted an owned capital from normal maintenance while retaining the
  occupied-claim premium and all unrelated maintenance behavior.
- Removed the `/nation city` and `/nationwarsdev` registrations and removed live
  city/port/coast/terrain doctrine calculations. Old serialized fields remain
  readable for compatibility.
- Replaced the requested American, British, and Italian doctrine effects.
- Removed automatic capital-capture capitulation; zero-territory elimination,
  surrender, and peace systems remain separate and unchanged.
- Ensured wartime trade offers are rejected in both UI and authoritative data
  layers.
- Corrected Scorched Earth's OPAC pass timing for physical block destruction.
- Added English, Romanian, Spanish, and Polish text for new player-facing
  feedback and updated doctrine lore in every catalog.

## Compatibility notes

- `MaintenanceMultiplierr` deliberately uses the exact double-r spelling in the
  supplied checklist.
- Urban Sprawl is interpreted as five or more claims per member, matching the
  stated 1/5 member-to-claim ratio.
- The global income multiplier applies to the capital term. The separately
  calculated member term remains outside it, as it was outside doctrine income
  multipliers before this release.
- American Dream's 1.5x effect is also passive-capital-only. It does not alter
  the established mining or farming reward multiplier.
- The stored city/coast data model is retained so updating cannot silently
  discard old save fields, although those fields no longer affect gameplay.
